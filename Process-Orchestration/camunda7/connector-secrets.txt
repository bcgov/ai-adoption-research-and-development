# Camunda Connectors Secrets File
# This file contains secrets for various connectors
# Secrets are accessed via the CONNECTORS_SECRET prefix in connector configurations
# See: https://docs.camunda.io/docs/self-managed/connectors-deployment/connectors-configuration/

# Example: AWS Connector Secrets
# CONNECTORS_SECRET_AWS_ACCESS_KEY_ID=your-aws-access-key-id
# CONNECTORS_SECRET_AWS_SECRET_ACCESS_KEY=your-aws-secret-access-key
# CONNECTORS_SECRET_AWS_REGION=us-east-1

# Example: Azure Connector Secrets
# CONNECTORS_SECRET_AZURE_CLIENT_ID=your-azure-client-id
# CONNECTORS_SECRET_AZURE_CLIENT_SECRET=your-azure-client-secret
# CONNECTORS_SECRET_AZURE_TENANT_ID=your-azure-tenant-id

# Example: Google Cloud Connector Secrets
# CONNECTORS_SECRET_GCP_PROJECT_ID=your-gcp-project-id
# CONNECTORS_SECRET_GCP_SERVICE_ACCOUNT_KEY=your-service-account-json-key

# Example: HTTP/REST Connector Secrets
# CONNECTORS_SECRET_HTTP_BASIC_AUTH_USERNAME=your-username
# CONNECTORS_SECRET_HTTP_BASIC_AUTH_PASSWORD=your-password
# CONNECTORS_SECRET_HTTP_BEARER_TOKEN=your-bearer-token

# Example: Database Connector Secrets
# CONNECTORS_SECRET_DB_USERNAME=your-db-username
# CONNECTORS_SECRET_DB_PASSWORD=your-db-password
# CONNECTORS_SECRET_DB_CONNECTION_STRING=your-db-connection-string

# Example: Email Connector Secrets (SMTP)
# CONNECTORS_SECRET_SMTP_USERNAME=your-smtp-username
# CONNECTORS_SECRET_SMTP_PASSWORD=your-smtp-password
# CONNECTORS_SECRET_SMTP_HOST=smtp.example.com
# CONNECTORS_SECRET_SMTP_PORT=587

# Example: Slack Connector Secrets
# CONNECTORS_SECRET_SLACK_BOT_TOKEN=xoxb-your-slack-bot-token
# CONNECTORS_SECRET_SLACK_WEBHOOK_URL=https://hooks.slack.com/services/your/webhook/url

# Example: GitHub Connector Secrets
# CONNECTORS_SECRET_GITHUB_TOKEN=your-github-personal-access-token

# Example: Generic API Keys
# CONNECTORS_SECRET_API_KEY=your-api-key
# CONNECTORS_SECRET_API_SECRET=your-api-secret

# Note: Uncomment and fill in the secrets you need for your connectors
# Make sure to add this file to .gitignore to avoid committing secrets!
